# License Control Center

chat, preciso criar um sistema de licenciamento para um projeto que eu fiz.

preciso que esse sistema rode em uma vps e tenha dominio https.
basicamente esse sistema de licenciamento eu vou fazer um cadastro do cliente que vai licenciar  e o sistema após isso vai gerar uma chave. essa mesma chave vai precisar ser validada na hora da instalação. precisa consultar e se a licença for valida permitir a instalação. caso contrario deverá bloquear.

quero ainda que após a licença online esse sistema do licenciamento seja possivel saber a url do sistema instalado, ip, status da instancia e a regiao onde foi instalada
